문제 해결 사례

증상이 나타난 화면에서 멈추지 않고, 데이터와 외부 연동을 포함한 처리 흐름 전체를 확인한 뒤 고쳤습니다.

사안 1문화비 소득공제 분납 결제의 가맹점 정보 불일치

증상 분납 결제의 후속 결제가 잘못된 가맹점 ID로 요청되고, 취소할 때도 승인 당시와 다른 가맹점 정보가 사용됨
원인 취소 로직이 실제 승인에 쓰인 가맹점 ID가 아니라 현재 설정값을 참조했고, 결제 요청 전에 상품의 소득공제 대상 여부와 가맹점 정보를 확인하지 않음
조치 취소 시 승인에 사용된 가맹점 ID를 참조하도록 수정하고, 결제 요청 전 소득공제 대상 여부와 가맹점 정보의 정합성을 검증하는 로직 추가
검증 실제 결제 테스트로 승인·취소가 같은 가맹점으로 처리되는 것을 확인
관련 사업 별지 제1호 2번 · 금천구시설관리공단

사안 2운영 통계 화면 504 Gateway Timeout

증상 운영 통계 조회가 90초 이상 걸려 게이트웨이 타임아웃(504) 발생
원인 쿼리 실행계획과 호출 구조를 분석한 결과, DB 함수 파라미터의 문자셋 불일치로 인덱스가 사용되지 않았고, 해당 쿼리가 312회 반복 호출되고 있었음
조치 함수 파라미터의 문자셋을 테이블과 일치시켜 인덱스를 타도록 수정
결과 90초 이상 → 수초 이내수정 후 재측정으로 확인
